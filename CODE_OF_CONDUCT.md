# Code of Conduct

This project is open source, and we expect contributors and users to treat
each other well.

## Our promise

Participants in this project are encouraged to:

- be respectful
- be constructive
- be honest about limitations
- avoid personal attacks
- keep security issues private until they are handled properly

## Responsibilities

Project maintainers are responsible for:

- clarifying standards
- addressing behavior that is not acceptable
- acting fairly and consistently

Contributors and users are responsible for:

- acting in good faith
- focusing on the work, not the person
- reporting serious problems through the appropriate channel

## Scope

This code applies in all project spaces: issues, pull requests, discussions,
code review, and any other official project communication.

## Enforcement

If you experience or witness unacceptable behavior, report it to the
maintainers. Reports will be handled with discretion.

Unacceptable behavior may result in a temporary or permanent response from
the maintainers, at their discretion.

## Attribution

This Code of Conduct is adapted from the Contributor Covenant, the standard
code of conduct for open source communities.

If you want the canonical reference, see
